# Boldrini

Projeto acadêmico de um site de apresentação para a clínica Boldrini,
localizada em Nova Iguaçu, RJ.

## Objetivo

Apresentar os tratamentos estéticos, com destaque para preenchimento
labial, e facilitar o contato pelo WhatsApp.

## Aprendizado

Praticar desenvolvimento web com auxílio de IA, Git, GitHub
e publicação de um site.

## Situação

Projeto em desenvolvimento.
